### Browser-only defect found and repaired

Real MapLibre testing exposed `TypeError: Failed to execute 'fetch' on 'Window': Illegal invocation`. `PinnedRangeSource.fetchRange` called an injected/global fetch as `this.request(...)`, giving it the cache instance as receiver. Node's fetch and arrow-function test doubles had hidden this defect.

The transport now invokes a local function reference, matching the existing catalogue-loader convention. A new regression failed before this change and passes afterward. Range bounds, SHA-256 verification, cancellation and cache limits are unchanged. Acceptance now requires successful scene commitment and rejects console errors, preventing a research benchmark from passing over a failed Atlas load.

## Gemini connection and safeguards

**Implementation and offline checks: PASS. Live authentication/transport: PASS. Live schema-conformant proposal: PASS (synthetic opt-in only).**

`research-semantic/gemini-provider.ts` implements the existing `PlannerProvider` interface in trusted Node code using direct HTTPS REST at `generativelanguage.googleapis.com`. It is not imported into the browser or the production historical controller. Historical planning remains unavailable under existing permissions; no browser-to-provider service or historical processing grant was enabled.

- Default model: `gemini-2.5-flash`; explicit model configuration and the live runner's `GEMINI_MODEL` override are supported. There is no automatic model fallback. This project received HTTP 404 for `gemini-2.5-flash`, so live checks used the user-selected override `gemini-3.8-flash`. Gemini 3 requests omit unsupported legacy sampling and candidate-count parameters.
- Credentials are opaque, header-safe strings: both standard and authorization key formats are accepted, while whitespace, control characters, assignments, wrapping and oversized values are rejected.
- The default synthetic profile allows 10 seconds per request. A separately named `synthetic-live-30s-v1` profile was explicitly approved for smoke tests and is capped at 30 seconds; token ceilings are unchanged.
- `generationConfig` now sends `responseMimeType: "application/json"` with an OpenAPI-subset `responseSchema` derived from the existing Zod contracts. The converter flattens nullable branches, converts tuples to homogeneous items with fixed lengths, keeps string enums, represents numeric constants as bounds, and removes JSON-Schema-only metadata, references and strict-object keywords from the wire form. Host schemas retain those stricter constraints. Root fields remain required; local envelope validation retains v1 dashboard compatibility, and QueryPlan plus trusted host validation independently recheck pins, scope, intent, references and views.
- Explicit synthetic-only consent is required for all six distinct transmitted fields and every dataset. Context identifiers and consent scope are restricted to synthetic fixtures. `PlannerBoundary` also requires `allowLiveSynthetic: true` and the synthetic disclosure marker.
- Production `PROVIDER_PROCESSING_POLICY`, source pins and historical data retain immutable `modelProcessing: false`. Isolated test consent is a separate grant, never a mutation of historical permissions.
- Credentials are loaded internally from `GEMINI_API_KEY`, or the explicitly supplied raw-key file named by `GEMINI_API_KEY_FILE`. They appear only in the authentication header, never URL parameters, prompt payloads, public configuration, logs, diagnostic receipts or replay exports. Credential-bearing prompt/output payloads are rejected.
- HTTPS destination is fixed; redirects, cookies, tools, code execution and automatic retries are disabled. No Gemini SDK dependency was added.
- Input/output/session budgets are mandatory. Full attempts are reserved before HTTP; only validated conservative charges are refunded. Charges take at least UTF-8 byte counts and include reported thinking/total usage. Unknown failed/cancelled costs retain their reservation.
- Missing credentials or budgets, exhausted reservations, and authentication/quota/model-unavailable responses fail closed with `PROVIDER_UNAVAILABLE`. Timeouts, cancellation, malformed output and over-budget replies use bounded, redacted error codes.
- The deadline covers headers and streamed body consumption. Caller cancellation and disposal abort transport and suppress late acceptance. Response bytes, JSON depth, unsafe/duplicate keys, output schemas and usage counters are bounded. Cancellation is not a guarantee that remote generation or billing stopped.

The **33 offline Gemini tests** exercise these paths using synthetic transports, including actual byte streams, stalled bodies, denial cases, opaque credential formats, the 30-second profile cap, OpenAPI wire-schema invariants, structured upstream-error reduction and planner integration. A final regression demonstrated that an upstream field string could escape the earlier character filter; diagnostics now emit only fixed allowlisted schema names, never arbitrary field contents or descriptions. The regression failed before the fix and passes afterward. These tests do not claim live model quality or endpoint conformance.
